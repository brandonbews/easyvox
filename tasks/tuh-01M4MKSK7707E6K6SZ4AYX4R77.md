## Description

Questions from the branding brief (10 Oct) that change the asset list. Each has a default to go with if you have no preference:

1. Dock: EasyVox is menu-bar only (no Dock, no ⌘-Tab). Should it ever show in the Dock, e.g. while Settings or setup is open? Default: no.
2. Name and domain: is "EasyVox" final, and is easyvox.dev registered? README links it and the bundle id uses it.
3. Menu bar icon states: today it never changes. Which states? Proposed: idle, recording, needs attention for v1; getting ready and downloading later. Each needs code.
4. App icon format: plain .icns (no Xcode needed, as now) or Icon Composer .icon (Dark, Clear and Tinted looks on macOS 26, but the build then needs Xcode 26)? Default: .icns.
5. Brand colour in the app: may the meter red, done green, notice amber, or the neutral Settings theme take a brand accent? Default: keep the system colours in the pill; an accent for buttons is open.
6. Website and public repo at v1: do they launch with the first DMG? That decides whether favicon and social cards are v1.
7. Auto-updater (see its own decision task): Sparkle would add an update window that shows the icon.

The full brief, with the Claude Design prompt, is the artifact "EasyVox Brand Brief".
