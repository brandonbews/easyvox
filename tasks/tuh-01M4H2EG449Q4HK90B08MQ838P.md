## Description

Setup: `scripts/bundle.sh && open dist/EasyVox.app` at an unlocked screen. The ad-hoc signature changes on every rebuild, so grant Accessibility (and Microphone) again after each one. Dictate the same few sentences into TextEdit with each setup and judge the feel:

- Parakeet Unified, 560 ms chunks (today's default): first words ~1.35 s; 7–9 % of a core while speaking.
- Parakeet TDT v2 (re-decode preview): first words ~0.47 s; 15–37 % of a core. Fetch it with `scripts/fetch-model.sh parakeet-tdt-0.6b-v2-q5_k_m-gguf`, then pick it in Settings.
- Parakeet Unified, 160 ms chunks: first words ~0.85 s, at about twice Unified's compute. Quit the app, then `open --env EASYVOX_PK_CHUNK_MS=160 dist/EasyVox.app`.

Note heat, fan and battery feel as well as speed.
