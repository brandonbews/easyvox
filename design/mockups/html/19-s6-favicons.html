Fitting the knot to the grid · 16 px at 6×
Centred
96 soft pixels
Fitted — shipped
84 soft pixels
The knot has no straight strokes to snap, so the fit was found by rendering: 486 placements (small scale steps and ⅛ px offsets), each drawn at 16 px with the 1.4 px line. The one kept has the fewest part-covered pixels and no ink outside the 16 × 16 box — the loop tops, bottoms and sides fall on whole pixels, so the loops stay open instead of greying together. The thread end stays inside the knot. favicon.svg carries the same numbers, so the browser draws this fit too.
